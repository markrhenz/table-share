## Week-by-week schedule

### WEEK 1 — Directory blitz (one Saturday afternoon, ~3 hours)

1. **Take 3 fresh screenshots** at 1280×720 in private window (no dark mode):
   - `marketing/screenshots/homepage-hero.png`
   - `marketing/screenshots/table-view.png`
   - `marketing/screenshots/pricing.png`
2. **Open `02-directories.md`** and `01-boilerplate.md` side by side
3. **Submit to all 10 directories** in one sitting (3-5 min each)
4. **Track each** as you go in the file itself (checkboxes already there)

### WEEK 2 — Reddit comments (15 min/day)

1. **Open `03-reddit-playbook.md`**
2. **Bookmark all 6 saved searches** in browser
3. **Set a 15-min daily alarm** — check searches, comment if Table Share genuinely fits, log it
4. **Don't post threads.** Only comment in existing ones.
5. After 7 days, you'll have 5-15 comments live. Each indexes in Google over time.

### WEEK 3 — HN + newsletters (focused 4 hours)

**Tuesday/Wednesday evening (9-11 PM PHT = 6-8 AM Pacific):**
1. Open `04-hn-and-ih-posts.md`
2. Post the HN "Ask HN" exactly as written
3. Engage for 24 hours (batched replies every 2-3 hours)

**Throughout the week:**
1. Open `05-newsletter-pitches.md`
2. Send ONE pitch per day, Mon-Fri (Console, Bytes, Pointer, TLDR)
3. Don't bulk-send. Don't follow up if no reply in 14 days.

### WEEK 4 — Indie Hackers + Social (3 hours total)

**Day 1:**
1. Open `04-hn-and-ih-posts.md` (the IH post section)
2. Post to https://www.indiehackers.com/post
3. Engage with every comment within 24h

**Days 2-3:**
1. Open `06-social-and-dms.md`
2. Set up Bluesky + Mastodon accounts
3. Make first posts on each
4. Send 5 founder DMs (one per day)

## Honest expectations

After 4 weeks of doing all of this:

- **Best case (10% probability):** HN front page OR Console.dev feature → 5,000+ visits → spike to 200+ users → solid Week 1 baseline
- **Realistic (60% probability):** 100-300 new visitors per week, 1-3 Pro conversions, lifetime tables 200-400
- **Worst case (30% probability):** 30-100 new visitors per week, 0-1 Pro conversions

In all three cases, **you build directory backlinks + indexed Reddit comments + a public IH milestone story** that compound over the next 6-12 months. Distribution work isn't linear — much of the payoff comes 3-6 months after the work.
